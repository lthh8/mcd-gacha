# 麦门图鉴 · Gacha Collection

把麦门的历史订单变成一本可收集的二次元卡牌图鉴。**粉丝向、纯娱乐、只读、无支付。**

## 0. 前置条件
- 已配置麦当劳 MCP（`mcp-config.example.json`，`url=https://mcp.mcd.cn`，Bearer Token），并已在连接器中启用。
- 若无 Token 或 MCP 不可用：退化为**纯本地 Demo 模式**（`index.html`），仅做随机抽卡，不读取任何账户数据。

「抽卡 / 单抽 / 十连 / 我的麦门图鉴 / 麦门报告 / 本命单品 / 欧气值」

## 3. 抽卡算法（确定性）
- 掉率：**SSR 5% / SR 15% / R 35% / N 45%**。
- 命中某稀有度后，在该档内等概率随机取一张。
- **十连保底**：10 抽中若全为 N，则将其中 1 张重抽至 R 及以上。
- 掉率与卡表可由用户调整，但默认如上。

## 4. 数据驱动（接 MCP 时）
调用**只读**接口后：
- **本命卡**：历史订单中出现频次最高的单品 → 映射到对应卡牌。
- **欧气值** = `(SSR×3 + SR×1.2) / 总抽数 × 100`，再叠加：
  - 订单热度权重（高频单品 +）
  - 会员资历权重（累计/可用积分 +）
- **卡牌三维**（美味 / 稀有 / 战力）：映射自单品价格、热量、个人消费频次。

## 5. 卡面生成（本命卡专属）
对「本命卡」可用多模态生图现场绘制专属卡面，提示词模板：
> Cute anime chibi mascot of {单品特征}, trading-card illustration, soft cell-shaded, vibrant, plain light background, highly detailed.
仅用只读数据，禁止生成含真实个人信息、Token 或不当内容。

## 6. 输出
1. **单抽**：翻转展示 1 张卡（SSR/SR 触发高亮动效）。
2. **十连**：2×5 网格依次翻牌。
3. **图鉴进度**：已收集 n/16 + SSR/SR 统计 + 欧气值（localStorage 持久化）。
4. **分享报告卡**：Canvas 合成 PNG（标题、收集度、本命卡、稀有度角标），供用户下载转发。

## 7. 分享标题判定
- SSR ≥ 2 → 欧皇本皇
- SSR = 1 → 麦门锦鲤
- 收集 16/16 → 图鉴收藏家
- 抽数 ≥ 20 → 麦门老饕
- 其他 → 麦门萌新

## 8. 边界与合规（必须遵守）
- **只读**：不创建订单、不支付、不修改账户。
- **不涉赌**：抽卡为纯娱乐，无真实货币/投注/兑现。
- **不贬低/对比麦当劳**：文案保持粉丝向、正面。
- **隐私**：Token 仅用环境变量，不写入任何仓库文件。

## 9. 可运行 Demo
`index.html` 为独立静态 Demo（无需 Token），完整体验抽卡/图鉴/报告卡，可作为 Skill 的交互说明与演示。
