## 版本 B · 开发者社群 / V2EX / 即刻（讲工艺和差异化）

> 参赛作品《麦门图鉴》：把麦当劳 MCP 的只读数据变成一本可收集的全息闪卡图鉴。
>
> 几个和榜单上其他项目不一样的点：
> 1. **卡面零 AI 生图成本**：16 张立绘全是手写 SVG 路径（feTurbulence 水彩边缘扰动），不烧一分钱 token；
> 2. **全息工艺**：冷调星空底 + CSS mix-blend-mode 镭射层 + 中心遮罩——参考宝可梦 PTCG「插画区哑光、边框反光」的工艺，图案永远不会被镭射糊掉；
> 3. **安全设计**：MCP 客户端对 35 个官方工具逐个研判白名单，28 个只读放行、7 个写操作（下单/领券/抽奖）全拦截，未知工具 fail-closed；
> 4. **传播设计**：抽完一键导出分享报告卡 PNG（收集度/本命卡/称号），晒图比晒代码链接转化高得多。
>
> Demo 单文件零依赖，浏览器打开即玩：https://github.com/lthh8/mcd-gacha
> 排名按 GitHub Star（10/26 00:00 截止），感谢支持！
